# Data

| File | Description | Source |
|------|-------------|--------|
| `millikan.txt` | Photoelectric effect: frequency (Hz), stopping voltage (V) | Newman, *Computational Physics*, Exercise 3.8 |
| `sunspots.txt` | Month index since Jan 1749, monthly sunspot number | Newman, *Computational Physics*, Exercise 3.1 |
| `velocities.txt` | Time (s), x-velocity (m/s) | Newman, *Computational Physics*, Exercise 5.1 |
| `decay_data.txt` | Time, measured value, uncertainty for an exponential decay | via [jstupak/ComputationalPhysics](https://github.com/jstupak/ComputationalPhysics) |
| `magic04.data` | MAGIC gamma telescope simulated events: 10 Hillas parameters + class (g/h) | [UCI ML Repository](https://archive.ics.uci.edu/dataset/159/magic+gamma+telescope), Bock et al., CC BY 4.0 |
| `radial_motion_star.tbl` | Stellar radial velocities (m/s) vs time (BJD) | NASA Exoplanet Archive |
| `GLB.Ts+dSST.csv` | Global surface temperature anomalies (°C) by month | [NASA GISTEMP](https://data.giss.nasa.gov/gistemp/) |
