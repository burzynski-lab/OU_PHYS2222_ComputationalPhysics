## Getting started: run everything in your browser

You do **not** need to install anything. All coursework uses Jupyter notebooks on [Google Colab](https://colab.research.google.com), which runs in your web browser and already has every package we use.

1. Sign in to Google (a personal Gmail account is fine).
2. Click the **Open in Colab** badge next to any notebook below.
3. **Immediately** choose **File → Save a copy in Drive**. Otherwise your changes are lost when you close the tab.
4. Submit your work on Canvas via **File → Download → Download .ipynb**.

Any notebook in this repository can also be opened by hand: in Colab, choose **File → Open notebook → GitHub**, and paste this repository's URL.

## Repository layout

```
LectureNotes/   lecture notebooks, numbered by week
Exercises/      weekly in-class exercises
Projects/       project descriptions and starter notebooks
Data/           data files used in notebooks and projects
Images/         figures embedded in notebooks
```

Notebooks load data straight from GitHub so they work in Colab without uploading files, e.g.


## Optional: running locally

Not required. If you want Python on your own computer, install [uv](https://docs.astral.sh/uv/), then from this directory run:

```bash
uv venv && uv pip install -r requirements.txt
uv run jupyter lab
```

Or open the repository in a [GitHub Codespace](https://github.com/features/codespaces) (free with the [GitHub Student Developer Pack](https://education.github.com/pack)); it is preconfigured by `.devcontainer/`.
